# multimcp-api

API FastAPI de multiMCP: ingesta de eventos, FinOps, latencia, trazas y evaluación RAG.

```bash
uv run multimcp-api
# o: uv run uvicorn multimcp_api.main:app --reload
```

Contratos en [`SPEC.md`](../../SPEC.md), sección 6. Configuración solo por variables de entorno (ver `.env.example` en la raíz cuando exista).
