Rules:
- Do not use world knowledge. Only the provided contexts count as evidence.
- If every material claim in the answer is grounded in the contexts, label it "supported".

- If a material claim lacks support in the contexts, label it "unsupported".
- context_relevance is a float from 0 to 1: the fraction of context fragments that help answer the query.

Return ONLY a JSON object with this shape:
{
  "context_relevance": 0.0,
  "hallucination_label": "supported",
  "rationale": "up to 500 characters"
}
